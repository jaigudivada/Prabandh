## 📋 Project Overview

**PRABANDH** is a comprehensive, issue management system designed to streamline campus complaint reporting and resolution. Built with modern web technologies, it provides a transparent, efficient, and user-friendly platform for students, supervisors, workers, and administrators to collaborate on issue management.

### 🎯 Why PRABANDH?

- **Transparency**: Complete visibility into issue status and resolution progress
- **Efficiency**: Streamlined workflow from reporting to resolution
- **Accountability**: Clear role-based responsibilities and tracking
- **Real-time Updates**: Instant notifications on status changes
- **User-Friendly**: Intuitive interface for all user types

### 🏫 Common Campus Issues Handled

- 🗑️ **Waste Management** - Garbage collection, recycling, sanitation issues
- ⚡ **Electrical Issues** - Power outages, faulty wiring, lighting problems
- 💧 **Water Leakage** - Pipe leaks, drainage issues, water supply problems
- 🏫 **Classroom Maintenance** - Furniture, equipment, facility repairs
- 🧹 **Cleanliness** - Hygiene concerns, cleaning requests
- 🏗️ **Infrastructure** - Building repairs, structural issues
- 📡 **General Complaints** - Wi-Fi, hostels, systems, and more

## 🔄 Workflow

```
┌─────────────────┐
│  Issue Reported │
│   by Student    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Issue Assigned │
│  by Supervisor  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Supervisor      │
│    Review       │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Worker         │
│  Resolution     │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Issue Completed │
│   & Verified    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   Feedback &    │
│   Closure       │
└─────────────────┘
```

### Workflow Stages

1. **Issue Reporting** 📝
   - Student submits issue with details
   - Photos uploaded (optional)
   - Priority and category selected
   - Location specified

2. **Issue Assignment** 🎯
   - Supervisor reviews new issues
   - Assigns to appropriate worker
   - Sets priority and deadline
   - Notifies assigned worker

3. **Supervisor Review** 👁️
   - Monitor progress regularly
   - Provide guidance if needed
   - Update status changes
   - Escalate if required

4. **Worker Resolution** 🔧
   - Worker acknowledges assignment
   - Performs necessary work
   - Updates progress
   - Adds completion notes

5. **Issue Completion** ✅
   - Worker marks as resolved
   - Supervisor verifies work
   - Status updated to "Completed"
   - Notifies original reporter

6. **Feedback & Closure** ⭐
   - Student provides feedback
   - Issue officially closed
   - Data archived for analytics
   - Performance metrics updated

## 🚀 Installation Guide

### Prerequisites

- **Node.js** (v18.x or higher)
- **npm** (comes with Node.js)
- **Git** (for cloning)

### Step 1: Clone the Repository

```bash
git clone https://github.com/yourusername/Prabandh.git
cd Prabandh
```

### Step 2: Backend Setup

```bash
# Navigate to backend directory
cd backend

# Install dependencies
npm install

# Create .env file
# (See Environment Variables section below)

# Start the backend server
npm start
```

The backend server will run on `http://localhost:5000`

### Step 3: Frontend Setup

Open a new terminal:

```bash
# Navigate to frontend directory
cd frontend

# Install dependencies
npm install

# Start the development server
npm run dev
```

The frontend will run on `http://localhost:3000`

### Step 4: Access the Application

Open your browser and navigate to:
```
http://localhost:3000
```

## 🔐 Environment Variables

Create a `.env` file in the `backend` directory with the following variables:

```env
# Server Configuration
PORT=5000

# JWT Secret Key (Generate a secure random string)
JWT_SECRET=your_super_secure_jwt_secret_key_here

# Node Environment
NODE_ENV=development

# CORS Configuration
FRONTEND_URL=http://localhost:3000
```

### Generating a Secure JWT Secret

```bash
# Using Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## 🚀 Deployment Guide

### 1. Push to GitHub

```bash
git add .
git commit -m "Initial production-ready setup"
git remote add origin https://github.com/YOUR_USERNAME/prabandh.git
git push -u origin main
```

### 2. Deploy Backend

The backend runs as a Node.js/Express server with file-based storage. Deploy it on a platform that supports persistent filesystems (not Vercel serverless).

**Recommended platforms:** Railway, Render, Fly.io, or a VPS.

1. Create a new project on your chosen platform
2. Link to your GitHub repository, root directory: `backend`
3. Set the following environment variables:

| Variable | Value | Description |
|----------|-------|-------------|
| `JWT_SECRET` | `<generate-a-secure-random-string>` | JWT signing secret |
| `NODE_ENV` | `production` | Production mode |
| `FRONTEND_URL` | `https://your-frontend.vercel.app` | CORS allowed origin |

4. Start command: `node server.js`

### 3. Deploy Frontend on Vercel

1. Go to [vercel.com](https://vercel.com) → Import Repository
2. Select the `prabandh` repository
3. Configure:
   - **Root Directory:** `frontend`
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. **Environment Variables:**

| Variable | Value | Description |
|----------|-------|-------------|
| `VITE_API_URL` | `https://your-backend-url.com` | Backend API URL |

5. Update `vercel.json` with your actual backend API URL

### 4. Post-Deployment Verification

- Visit your frontend URL
- Test login with your credentials
- Navigate through all routes
- Refresh page on nested routes — should work
- Test file upload and logout

### ⚠️ Security Notes

1. **Never commit** `backend/.env` or `backend/data.json` to git
2. **Generate a strong JWT_SECRET** using: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`
3. File uploads are stored on the server filesystem — for production, use a cloud storage service (AWS S3, Cloudinary) for file persistence
